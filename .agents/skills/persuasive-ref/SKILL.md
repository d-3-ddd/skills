# persuasive-ref

質問に対し、信頼できる情報源に基づく簡潔な回答を、情報源の信頼度と原文の引用つきで返す。

## 手順

1. **情報収集**: Web検索とページ取得で根拠を集める。公式ドキュメント・公式発表・仕様書・法令・論文などの一次情報を優先し、見つからないときだけ二次情報を使う。
2. **回答の作成**: 集めた情報源から回答を導く。情報源に書かれていないことを推測で補わない。
3. **セルフチェック**: 出力の前に次の点を確認し、問題があれば自己修正する。
   - 回答の内容が、引用した文章で実際に裏付けられているか
   - 引用文が情報源の原文どおりか（要約・言い換えになっていないか）
   - 信頼度の判定が下記の定義に合っているか
4. **URLの確認**: 引用元のURLを実際に取得し、リンク切れや内容の食い違いがないことを確かめる。確認できなかったURLは使わない。
5. **出力**: 下記のフォーマットだけを出力する。

## 信頼度の定義

| ランク | 定義 |
|---|---|
| S | 公式の一次情報 |
| A | 公式ではないが、信頼性が高いといえる情報源 |
| B | 信頼性の低い二次情報 |
| W | 回答の根拠として十分な情報源を得られなかった |

複数の情報源を使った場合は、回答の結論を裏付けている情報源のうち、最も信頼度の高いもので判定する。

## 出力フォーマット

```
## 情報源の信頼度

{S / A / B / W のいずれか}


## 回答

{回答}


## 回答の根拠
> {回答の根拠とした文章}
> [{引用元のタイトル}]({引用元のURL})
```

- 回答は簡潔に書き、前置きや質問と関係のない情報を混ぜない。
- 根拠が複数あるときは、引用ブロックを情報源ごとに繰り返す。
- ランクがWのときは、十分な根拠が見つからなかったことと、確認できた範囲の事実だけを回答に書く。根拠には参照した情報源があれば記載し、なければ「なし」とする。
