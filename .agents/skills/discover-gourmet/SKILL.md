# 設定情報（共有URL）
- Favorite_List_URL: "https://maps.app.goo.gl/XXXXX" # 「行って良かった」リストの共有URL
- WantToGo_List_URL: "https://maps.app.goo.gl/YYYYY" # 「行きたいところ」リストの共有URL

# 処理手順
1. **入力解析**:
   ユーザーから渡された「エリア / ジャンル / 予算 / こだわり」を抽出する。

2. **Google Mapsリストの最新化（Computer Use不要・Web fetch）**:
   - 上記の共有URLにアクセスし、最新の登録店舗データをバックグラウンドで取得（スクレイピング）する。
   - 取得したリスト内から「指定エリア付近の店舗」および「ユーザーの好み傾向（ジャンル・雰囲気）」を解析する。

3. **新規開拓用のDeep Research**:
   - 入力条件に合致する店舗をWeb検索し、評価の高い店舗を2〜3つ選定する。
   - 各店舗の「食べログURL」を特定する。

4. **統合出力**:
   - 思考プロセスや無駄な解説文はすべてカットし、以下の指定フォーマットのみを出力する。
